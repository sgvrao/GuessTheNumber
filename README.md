🎯 Guess the Number — Refined Logic
Set maximum attempts = 5
Start a loop that runs for 5 attempts
Ask the user to enter a number
Compare the entered number with the correct number (7)
If the number is 7:
Print "You Won!"
Stop the loop
If the number is not 7:
Print "Wrong Guess! Try Again."
Decrease the attempts
If all 5 attempts are used without guessing correctly:
Print "You Lost!"
