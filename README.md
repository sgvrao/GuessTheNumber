🎯 Guess the Number — Refined Logic<br>
1] Set maximum attempts = 5<br>
2] Start a loop that runs for 5 attempts<br>
3] Ask the user to enter a number<br>
4] Compare the entered number with the correct number (7)<br>
5] If the number is 7:<br>
    Print "You Won!"<br>
    Stop the loop<br>
6] If the number is not 7:<br>
    Print "Wrong Guess! Try Again."<br>
    Decrease the attempts<br>
7] If all 5 attempts are used without guessing correctly:<br>
    Print "You Lost!"<br>
